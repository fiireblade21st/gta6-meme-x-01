## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only, no network) copies `POST.json` from the repository root to `/output/POST.json`. The post itself is the entry: `meme.png` is the meme picture, posted on X from a public account with a make.fun link, a tag of `@makefunai`, and the play code `makefun-sapling-scarf-cartoon` in its text. `POST.json` names the post's address after it is posted.
